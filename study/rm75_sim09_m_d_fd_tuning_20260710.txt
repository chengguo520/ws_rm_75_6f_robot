RM75-6F sim_09 M / D / Fd 控制变量调参记录（2026-07-10）
========================================================

实验目的
--------
在 Gazebo 虚拟接触模型中固定正弦曲面和擦拭速度，只改变法向导纳质量 M、阻尼 D、期望法向力 Fd，判断当前默认参数是否需要修改。

固定条件
--------
- mode=x_wave
- line_length=0.180 m
- line_speed=0.004 m/s
- wave_height=0.014 m
- wave_cycles=2
- surface_stiffness=1000 N/m
- surface_damping=12 N s/m
- max_z_velocity=0.014 m/s
- control_rate=30 Hz
- 每个正式轮次 90 s，覆盖中心 -> 右端 -> 中心 -> 左端 -> 中心的完整轨迹周期。
- 每轮前 5 s 作为参数切换瞬态，稳态 RMS 从 5 s 后计算；全过程峰值另行保留。

参数结论
--------
1. M 保持 1.5 kg。
   0.75/1.5/3.0 kg 的稳态结果几乎相同，力 RMS 最大差异不到 0.002 N，说明当前慢速正弦曲面由阻尼项主导。1.5 kg 位于区间中部，run 2 的关节误差峰值也最低（0.0068 rad），比选择边界值更保守。

2. D 保持 65 N s/m。
   D=40 时系统欠阻尼，z 速度有 38.42% 的样本撞到限幅，力 RMS 变为 D=65 的约 3.2 倍。D=90 虽然平滑无饱和，但力 RMS 比 D=65 高约 39%，表现为曲面跟随滞后。65 是本轮稳定性与跟随速度的最佳折中。

3. Fd 保持 6 N。
   8 N 的稳态力 RMS 只比 6 N 小约 0.003 N，这个微小差异不足以支持额外增加 2 N 接触载荷。4 N 的速度饱和、xy/关节误差和最小奇异值均略差。6 N 没有稳态速度饱和，接触载荷适中，综合最均衡。

4. 当前默认参数确实已经调得较好，不建议为了得到不同数值而修改。
   run 2 与最终 run 8 的力 RMS 为 0.206/0.208 N，eq RMS 都为 0.219 mm，重复差异约 1%。这说明结论不是一次偶然曲线。

调参经验
--------
- 控制变量实验必须覆盖完整轨迹周期。45 s 虽然回到线中心，但下一轮会换到另一侧构型，会把左右侧奇异性和 xy 误差混入参数影响。
- M 主要影响瞬态加速度；在很慢、很平滑的曲面上，单独看稳态 RMS 很难辨别 M。后续提高速度做鲁棒性测试时，M 的差异才会更明显。
- D 太小不只是“更灵敏”，还可能让虚拟接触弹簧、表面阻尼和离散控制外环形成振荡。首先看速度饱和率，再看力 RMS。
- D 太大虽然视觉上平滑，却会增加相位滞后和动态力误差。平滑不等于跟踪准确。
- Fd 改变静态压入量 Fd/Ks，也会改变 TCP 平衡高度和机械臂构型。不能只按力误差百分比选择 Fd。
- 在线大幅改变 Fd 会产生速度限幅瞬态。本轮从 4 N 直接切到 8 N 时全过程力峰较大，因此实物上必须使用斜坡给定，不能阶跃切换。
- 当前结果只证明固定 14 mm 曲面、4 mm/s 速度下有效。下一阶段应保持 M=1.5、D=65、Fd=6，改变曲面高度和擦拭速度验证鲁棒性。
