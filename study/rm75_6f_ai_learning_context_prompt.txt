四、ROS package 结构
===================

rm_75_6f_description
  机器人模型、URDF/Xacro、固定两指夹爪、RViz 显示、Gazebo 模型。

rm_75_gazebo
  Gazebo 启动、world、ros_control 控制器、仿真 bringup。

rm_75_moveit_config
  MoveIt 配置、SRDF、controllers.yaml、controllers_gazebo.yaml、规划参数。

rm_75_driver
  连接真实机械臂控制器的 ROS driver。

rm_75_control
  实物轨迹控制桥接，把 MoveIt action 轨迹转换为驱动使用的 JointPos。

rm_75_demo
  仿真和实物演示脚本。
  重要脚本包括：
  - sim_01_scene_plan.py
  - sim_02_vision_approach.py
  - sim_03_gripper_pick.py
  - sim_05_admittance_virtual_force.py

  - sim_07_admittance_ik_position.py
  - sim_08_admittance_jacobian_velocity.py
  - real_single_joint_step.py
  - real_wrist_small_step.py

rm_75_real_force_control
  实物六维力和拖动示教工具。
  重要文件包括：
  - src/rm75_force_read_only_node.cpp
  - src/rm75_drag_teach_node.cpp

五、AI 应该带用户走的学习顺序
=============================

推荐顺序：

1. 看官方用户手册，先理解安全和硬件。
2. 看 C++ API 说明，先知道厂家提供了哪些底层能力。
3. 编译工作区，确认 ROS 环境正常。
4. 用 RViz 只显示模型，不动仿真也不动实物。
5. 启动 Gazebo + MoveIt，在仿真里让机械臂运动。
6. 学 MoveIt 规划和执行，理解 planning scene、collision object、trajectory action。
7. 跑 sim_01 / sim_02 / sim_03，理解场景、视觉、抓取流程。
8. 跑 sim_05 到 sim_08，理解导纳控制、IK、Jacobian、限幅。
9. 连接实物机械臂，只做 ping 和 joint_states 检查。
10. 用 MoveIt 对实物做小幅、低速关节运动。
11. 读取六维力，学会清零和观察方向。
12. 启动普通拖动示教，学会 start/stop。
13. 再研究官方力位混合接口 Set_Force_Postion。
14. 最后考虑低速接触、恒力、擦桌子等应用。


六、最常用命令
==============

进入工作区：

cd /home/ros/ws_rm_75_6f_robot
source /opt/ros/noetic/setup.bash
source devel/setup.bash

编译整个工作区：

catkin build

只编译实物力控包：

catkin build rm_75_real_force_control

RViz 只看模型：

roslaunch rm_75_6f_description display.launch

Gazebo + MoveIt：

roslaunch rm_75_gazebo arm_75_bringup_moveit.launch

带桌子、方块、RGB-D 相机：

roslaunch rm_75_gazebo arm_75_bringup_moveit.launch \
  world_name:=$(rospack find rm_75_gazebo)/worlds/rm75_table_cube.world \
  use_rgbd_camera:=true

检查 Gazebo 控制器：

rostopic list | grep arm_joint_controller

仿真导纳 Jacobian 速度实验：

rosrun rm_75_demo sim_08_admittance_jacobian_velocity.py

检查仿真导纳状态：

rostopic echo /rm75_admittance_jacobian/state

检查实物网络：

ping 192.168.1.18

启动实物轨迹控制：

roslaunch rm_75_control rm_75_control.launch

启动实物 driver + MoveIt + RViz：

roslaunch rm_75_bringup rm_robot.launch arm_ip:=192.168.1.18

查看关节反馈：

rostopic echo -n1 /joint_states

查看实物 trajectory action：

rostopic list | grep follow_joint_trajectory

实物腕部小幅运动，先规划：

rosrun rm_75_demo real_wrist_small_step.py --delta 0.03 --velocity 0.05 --acceleration 0.05

实物腕部小幅运动，确认安全后执行：

rosrun rm_75_demo real_wrist_small_step.py --delta 0.03 --velocity 0.05 --acceleration 0.05 --execute

实物单关节小幅运动：

rosrun rm_75_demo real_single_joint_step.py --joint joint6 --degrees 20 --velocity 0.05 --acceleration 0.05 --execute

读取六维力：

roslaunch rm_75_real_force_control force_read_only.launch

查看六维力 topic：

rostopic echo /rm75_force_sensor/wrench

六维力清零：

rosservice call /rm75_force_sensor/zero

启动普通拖动示教节点：

roslaunch rm_75_real_force_control drag_teach.launch use_multi_drag:=false

进入拖动示教：

rosservice call /rm75_drag_teach/start

退出拖动示教：

rosservice call /rm75_drag_teach/stop

限时 10 秒拖动示教测试：

roslaunch rm_75_real_force_control drag_teach.launch auto_start:=true auto_stop_after_sec:=10 use_multi_drag:=false

八、柔顺控制概念解释要求
========================

AI 解释柔顺控制时，应按下面思路讲：

1. 阻抗控制：
   位置误差产生力。
   更像“机械臂表现得像弹簧/阻尼/质量系统”。

2. 导纳控制：
   外力产生位移或速度。
   当前 Gazebo 位置控制器更适合外层导纳控制。

3. 六维力/力矩：
   Fx、Fy、Fz 单位通常是 N。
   Mx、My、Mz 单位通常是 Nm。
   必须说明坐标系，是基坐标系还是工具坐标系。

4. M/D/K：
   M 是虚拟质量。
   D 是虚拟阻尼。
   K 是虚拟刚度。
   参数过小或限幅不够会导致抖动、漂移或危险动作。

5. 限幅：
   必须限制最大位移、最大速度、最大关节步长、最大力。
   实物第一轮应该使用极小速度、极小力、软接触。

6. 力位混合：
   位置方向仍由轨迹控制。
   指定方向由底层保持或补偿力。
   适合后续擦桌子：XY 走轨迹，Z 保持 2N 到 5N 小接触力。


九、官方实物柔顺接口要点
========================

已重点整理的官方接口：

1. Get_Force_Data
   读取六维力数据。
   当前已封装到 rm75_force_read_only_node。

2. Clear_Force_Data
   六维力清零。
   当前通过 ROS service /rm75_force_sensor/zero 调用。

3. Start_Drag_Teach
   普通拖动示教。
   当前已验证成功。

4. Stop_Drag_Teach
   停止拖动示教。
   当前已验证成功。

5. Start_Multi_Drag_Teach
   复合六维力拖动示教。
   当前 mode=1 返回 1，表示控制器拒绝，需要继续排查。

6. Set_Force_Postion
   官方普通力位混合接口。
   注意官方函数名里是 Postion，不是 Position。

   参数含义：
   sensor:
   0 = 一维力
   1 = 六维力

   mode:
   0 = 基坐标系
   1 = 工具坐标系

   direction:
   0 = X
   1 = Y
   2 = Z
   3 = Rx
   4 = Ry
   5 = Rz

   N:
   单位是 0.1N。
   20 = 2N。
   50 = 5N。

   推荐第一轮概念测试：
   Set_Force_Postion(sock, 1, 1, 2, 20, RM_BLOCK)
   含义：六维力、工具坐标系、Z 方向、2N。

7. Stop_Force_Postion
   停止普通力位混合。

8. 透传力位混合：
   Start_Force_Position_Move
   Force_Position_Move_POSE
   Force_Position_Move_Joint
   Stop_Force_Postion_Move

   注意：
   Force_Position_Move_* 里的 force 单位是 N。
   Set_Force_Postion 里的 N 单位是 0.1N。

十一、AI 回答实物操作时的安全规则
================================

AI 只要涉及实物运动，就必须提醒：

1. 急停必须可触达。
2. 机械臂周围不得有人、线缆、工具或障碍物。
3. 第一次执行只做小幅运动。
4. 速度和加速度先用 0.05。
5. MoveIt 中先 Plan，再 Execute。
6. 不要使用 random target 做实物第一次测试。
7. 拖动示教必须知道 stop 命令。
8. 力位混合必须知道 Stop_Force_Postion。
9. 六维力清零要在末端静止、悬空、不接触外物时做。
10. 实物柔顺接触第一轮只用 2N 级别小力，不做硬接触。
